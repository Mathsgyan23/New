GITHUB PAGES
1. Upload the entire contents of this folder to the root of a GitHub repository.
2. Keep index.html at the repository root and keep the subjects folder with all its files.
3. Open repository Settings > Pages.
4. Choose Deploy from a branch, branch main, folder /(root), then Save.
5. Open the published GitHub Pages URL.

NOTES
- Original subject HTML files are preserved as separate files. Their built-in content, scripts and visual tools remain in place.
- The home page includes a shared searchable notation table and subject navigation.
- Internet is needed for remote background images, fonts, KaTeX or other external libraries referenced by source pages.
- A visual should be placed beside the exact definition/theorem/example it explains. This bundle preserves existing source visuals; it does not claim newly generated diagrams have been inserted beside every theorem. That requires lesson-by-lesson review and editing.
