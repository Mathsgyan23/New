UNIT I

Transcendental & Polynomial Equations (15 Lectures)

1. Bisection Method

Order p = 1

Based on Bolzano's Intermediate Value Theorem: If $f(a)f(b) < 0$, a real root $\xi \in (a,b)$ exists. Repeatedly bisects the bracket interval.

$$x_{k+1} = \frac{a_k + b_k}{2}, \quad |x_k - \xi| \le \frac{b - a}{2^k} \le \epsilon$$

Iterations needed: $n \ge \frac{\log(b - a) - \log \epsilon}{\log 2}$. Guaranteed convergence.

2. Secant & Regula-Falsi

p = 1.618 / 1.0

Approximates $f(x)$ by a first-degree linear secant chord through $(x_{k-1}, f_{k-1})$ and $(x_k, f_k)$.

$$x_{k+1} = x_k - \frac{x_k - x_{k-1}}{f_k - f_{k-1}} f_k$$

Secant: $\alpha = \frac{1+\sqrt{5}}{2} \approx 1.618$ (Superlinear).
Regula-Falsi: Bracket maintained, linear rate of convergence ($p = 1$).

3. Newton-Raphson

Order p = 2

Replaces the curve locally by its tangent line at $(x_k, f(x_k))$. Requires $f'(x_k) \ne 0$.

$$x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}$$

Possesses quadratic convergence ($p = 2$) for simple roots. For roots of multiplicity $m \ge 2$, the order drops to 1.

Derivation: Order of Convergence of Newton-Raphson Method

Let $\xi$ be a simple root so that $f(\xi) = 0$ and $f'(\xi) \ne 0$. Let the error at step $k$ be $\epsilon_k = x_k - \xi$, which implies $x_k = \xi + \epsilon_k$.

Substituting $x_k$ into the iterative scheme gives:

$$\epsilon_{k+1} = \epsilon_k - \frac{f(\xi + \epsilon_k)}{f'(\xi + \epsilon_k)}$$ $$= \epsilon_k - \frac{\epsilon_k f'(\xi) + \frac{\epsilon_k^2}{2} f''(\xi) + \mathcal{O}(\epsilon_k^3)}{f'(\xi) + \epsilon_k f''(\xi) + \mathcal{O}(\epsilon_k^2)}$$ $$= \epsilon_k - \left[\epsilon_k + \frac{\epsilon_k^2}{2}\frac{f''(\xi)}{f'(\xi)}\right] \left[1 + \epsilon_k \frac{f''(\xi)}{f'(\xi)}\right]^{-1}$$ $$= \epsilon_k - \left[\epsilon_k + \frac{\epsilon_k^2}{2}\frac{f''(\xi)}{f'(\xi)}\right] \left[1 - \epsilon_k \frac{f''(\xi)}{f'(\xi)} + \mathcal{O}(\epsilon_k^2)\right]$$ $$\epsilon_{k+1} = \frac{1}{2}\frac{f''(\xi)}{f'(\xi)} \epsilon_k^2 + \mathcal{O}(\epsilon_k^3)$$

Thus, the error equation is $\epsilon_{k+1} = C \epsilon_k^2$ where $C = \frac{1}{2}\frac{f''(\xi)}{f'(\xi)}$, proving second-order (quadratic) convergence.

Birge-Vieta Method (Real Roots)

Extracts linear factor $(x - p)$ from polynomial $P_n(x) = a_0 x^n + a_1 x^{n-1} + \dots + a_n = 0$. Evaluates $P_n(p)$ and $P'_n(p)$ using Horner's synthetic division scheme:

$b_0 = a_0, \quad b_k = a_k + p b_{k-1} \implies b_n = P_n(p) = R$
$c_0 = b_0, \quad c_k = b_k + p c_{k-1} \implies c_{n-1} = P'_n(p) = \frac{dR}{dp}$
$$p_{k+1} = p_k - \frac{b_n}{c_{n-1}}$$

After convergence to desired accuracy, the quotient polynomial $Q_{n-1}(x) = \sum b_k x^{n-1-k}$ is used for deflation.

Bairstow's Method (Quadratic Factors)

Extracts quadratic factors $x^2 + px + q$ to locate complex conjugate roots of real polynomials without using complex numbers:

$P_n(x) = (x^2 + px + q)Q_{n-2}(x) + R x + S$
$b_k = a_k - p b_{k-1} - q b_{k-2}, \quad c_k = b_k - p c_{k-1} - q c_{k-2}$
$$\Delta p = -\frac{b_n c_{n-3} - b_{n-1} c_{n-2}}{c_{n-2}^2 - c_{n-3}(c_{n-1} - b_{n-1})}$$
$$\Delta q = -\frac{b_{n-1}(c_{n-1} - b_{n-1}) - b_n c_{n-2}}{c_{n-2}^2 - c_{n-3}(c_{n-1} - b_{n-1})}$$

Updated values: $p_{k+1} = p_k + \Delta p$, $q_{k+1} = q_k + \Delta q$.

UNIT II

System of Linear Equations & Eigenvalues (15 Lectures)

Matrix Factorization (LU Decomposition)

Decomposes coefficient matrix $A = LU$. Transforms $Ax = b$ into two triangular systems: Forward substitution $L z = b$, followed by back-substitution $U x = z$.

Doolittle's Method

Unit lower triangular matrix ($l_{ii} = 1$).

$$\text{diag}(L) = [1, 1, \dots, 1]$$
Crout's Method

Unit upper triangular matrix ($u_{ii} = 1$).

$$\text{diag}(U) = [1, 1, \dots, 1]$$

Stationary Iteration Solvers

Splits $A = D + L + U$. The general linear iteration $x^{(k+1)} = H x^{(k)} + c$ converges for any initial vector iff the spectral radius $\rho(H) < 1$.

Jacobi Method: $H_J = -D^{-1}(L+U), \quad c = D^{-1}b$
Gauss-Seidel: $H_{GS} = -(D+L)^{-1}U, \quad c = (D+L)^{-1}b$

Rate of convergence: $\nu = -\log_{10} [\rho(H)]$. Strict diagonal dominance $|a_{ii}| > \sum_{j \ne i} |a_{ij}|$ guarantees convergence for both.

Eigenvalue Bounds: Gerschgorin & Brauer Theorems

Gerschgorin Circle Theorem

Every eigenvalue $\lambda$ of square matrix $A \in \mathbb{C}^{n \times n}$ lies in the union of $n$ closed Gerschgorin discs:

$$|\lambda - a_{ii}| \le R_i = \sum_{j \ne i} |a_{ij}|$$

Also holds for columns since $\det(A - \lambda I) = \det(A^T - \lambda I)$. Thus eigenvalues lie in the intersection of row and column disc unions.

Brauer Cassinian Theorem

Every eigenvalue lies in the union of $n(n-1)/2$ Cassinian ovals:

$$|\lambda - a_{ii}||\lambda - a_{jj}| \le R_i R_j \quad (i \ne j)$$

Yields tighter localized regions than Gerschgorin discs when off-diagonal sums differ significantly.

Jacobi Method for Symmetric Matrices

Eliminates the largest off-diagonal elements $a_{ik}$ via a series of plane orthogonal transformations $B = S^T A S$:

$$\tan 2\theta = \frac{2 a_{ik}}{a_{ii} - a_{kk}}, \quad |\theta| \le \frac{\pi}{4}$$

As iterations proceed, $B_r$ approaches a purely diagonal matrix whose diagonal elements are the eigenvalues, and $S = \prod S_r$ contains the eigenvectors.

Power Method (Dominant Eigenpair)

Computes the dominant eigenvalue $|\lambda_1| > |\lambda_2| \ge \dots \ge |\lambda_n|$ and its associated eigenvector:

$$y_{k+1} = A v_k, \quad m_{k+1} = \max |y_{k+1}|, \quad v_{k+1} = \frac{y_{k+1}}{m_{k+1}}$$ $$\lambda_1 = \lim_{k \to \infty} \frac{(A v_k)_r}{(v_k)_r}$$

The Rayleigh quotient $q_k = \frac{v_k^T A v_k}{v_k^T v_k}$ accelerates eigenvalue estimation.
